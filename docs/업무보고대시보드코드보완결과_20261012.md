## 3. 입력 자료 정리 (사실 변경 없음)

| 항목 | 정리 내용 |

| 2027년 사업계획 수립 | 같은 사실의 중복 3줄 제거(9월 29일 1차 제출, 11월 13일 발표회 장소 예약, 10월 8일 중장기 자금계획 제출) |
| 수익성 분석 및 개선 제언 | '4분기 목표표에는 … 기재됨'을 '4분기 과제: …'로 정리 |

## 5. 운영 반영 시 별도 설계 필요 사항 (변경 없음)

JSON 파일 저장소, 로컬 로그인(누구나 임의 구성원 선택), 다른 팀 작성 중 초안 공개(`previewAllTeams`), 감사 이벤트 미등록, 로컬 목표 ID 연결은 로컬 검토판 전제이므로 운영 반영 시 DB, SSO, 공개 범위, `audit_registry.py`, 운영 목표 ID 기준으로 다시 설계해야 합니다. 회차는 두 팀 공용이므로 어느 팀장이든 생성할 수 있는 현재 방식을 유지하였습니다.
